NEPAL PREMIUM STORE — READY LOCAL VERSION

1) Copy the entire nepal-premium-store folder to C:\xampp\htdocs\nepal-premium-store
2) Start Apache and MySQL in XAMPP.
3) Existing database does not need to be imported again.

GOOGLE SHEETS:
- Tab name: Invoices
- Headers: Invoice No | Customer Name | Contact | User ID | Password | Profile | PIN | Item | Plan | Duration | Price | Issue Date | Expiry Date | Status
- The PHP config already contains the provided Web App URL and token.
- If Sync says Invalid token, the deployed Apps Script is using a different/older token. In Google Apps Script, open the project, make sure CONFIG.TOKEN is NPS2026_SYNC_9xK72, Save, then Deploy > Manage deployments > Edit > New version > Deploy. This is the only Google-side step required.
